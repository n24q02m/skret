# Security Policy

## Supported Versions

The latest stable release receives security fixes. Older stable releases and prereleases are unsupported unless a published advisory explicitly says otherwise.

## Reporting a Vulnerability

Use GitHub's private vulnerability-reporting form:

<https://github.com/n24q02m/skret/security/advisories/new>

Do not open a public issue or include a secret, credential, exploit payload, or private environment detail in a public discussion. Include the affected version, impact, minimal reproduction, and any known mitigation in the private report.
